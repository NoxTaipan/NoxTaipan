# Hola, soy Nox 👋

Streamer y developer. Construyo herramientas de código abierto para mi propio setup de stream, y las comparto para que cualquier otro streamer las pueda auto-hospedar.

## 🧩 Confluence Suite

Un set de herramientas para controlar Twitch, YouTube y Kick a la vez desde OBS, sin depender de ningún servicio de terceros — cada quien corre su propia instancia en su propia PC.

| | |
|---|---|
| 🖥️ [**confluence-beta**](https://github.com/NoxTaipan/confluence-beta) | Panel web (OBS dock): título/tags/categoría a la vez + chat unificado de las tres plataformas. |
| 🔀 [**confluence-multistream**](https://github.com/NoxTaipan/confluence-multistream) | Plugin nativo de OBS para mandar el stream a varios destinos RTMP a la vez. |
| 🎛️ [**confluence-streamdeck-beta**](https://github.com/NoxTaipan/confluence-streamdeck-beta) | Plugin de Elgato Stream Deck para controlar todo lo anterior desde botones físicos. |
