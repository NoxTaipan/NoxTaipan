## 🧩 Confluence Suite

**ES:** Un set de herramientas para controlar Twitch, YouTube y Kick a la vez desde OBS, sin depender de ningún servicio de terceros — cada quien corre su propia instancia en su propia PC.

**EN:** A set of tools to control Twitch, YouTube and Kick at once from OBS, with no third-party service involved — everyone runs their own instance on their own PC.

| | ES | EN |
|---|---|---|
| 🖥️ [**confluence-beta**](https://github.com/NoxTaipan/confluence-beta) | Panel web (OBS dock): título/tags/categoría a la vez + chat unificado de las tres plataformas. | Web panel (OBS dock): title/tags/category at once + unified chat for all three platforms. |
| 🔀 [**confluence-multistream**](https://github.com/NoxTaipan/confluence-multistream) | Plugin nativo de OBS para mandar el stream a varios destinos RTMP a la vez. | Native OBS plugin to send the stream to several RTMP destinations at once. |
| 🎛️ [**confluence-streamdeck-beta**](https://github.com/NoxTaipan/confluence-streamdeck-beta) | Plugin de Elgato Stream Deck para controlar todo lo anterior desde botones físicos. | Elgato Stream Deck plugin to control all of the above from physical buttons. |
